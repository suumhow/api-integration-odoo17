# Odoo API Integration Module

This module provides custom API endpoints for retrieving and pushing data from Odoo to external services.

## Features
- Custom API endpoints for data retrieval
- Automatic data synchronization with external services
- Support for companies and contacts management
- CRM integration

## Installation
1. Clone this repository into your Odoo addons directory
2. Update your Odoo addons list
3. Install the module through Odoo's UI

## Configuration
1. Set up your API key in System Parameters
2. Configure the CU schema parameter
3. Enable the necessary endpoints
